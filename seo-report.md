# SEO & Metadata Audit — ServiceWindow

**Date:** 2026-09-14
**Scope:** 15 production HTML pages (see list below)
**Method:** Automated check of `<title>`, `<meta name="description">`, Open Graph tags, `<link rel="canonical">`, JSON-LD structured data, and `<meta name="robots">` in each file's `<head>`. Report only — no HTML files were modified.

## Summary

- **Pages audited:** 15
- **Total issues found:** 34
- **Legend:** ✅ Pass · ⚠️ Present but needs improvement · ❌ Fail / missing

### Top 3 Priority Fixes

1. **Missing `<link rel="canonical">`** on 6 pages — `auth.html`, `privacy.html`, `terms.html`, `success.html`, `cancel.html`, `reset-password.html`. Canonical tags prevent duplicate-content ambiguity and should be added to every page, even ones that are `noindex`.
2. **Missing Open Graph tags** (`og:title`, `og:description`, `og:url`) on `success.html`, `cancel.html`, `reset-password.html` — only `og:image` is present on these. Links to these pages will render broken/blank previews when shared.
3. **Meta description length outside the 120–160 char target** on 8 pages — `marketplace.html` (161, 1 over), `auth.html` (95), `contact.html` (98), `privacy.html` (116), `terms.html` (92), `success.html` (48), `cancel.html` (53), `reset-password.html` (34). The short ones are well under target and read as thin snippets in search results.

**Note on `robots noindex`:** `auth.html`, `success.html`, `cancel.html`, and `reset-password.html` all set `<meta name="robots" content="noindex, nofollow">`. This is flagged per the audit criteria (no production page should be noindexed), but is very likely intentional for a login/auth screen and post-Stripe transactional pages, which normally shouldn't be indexed. Flagged for awareness, not necessarily a fix.

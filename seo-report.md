# SEO & Metadata Audit — ServiceWindow

**Audit date:** 2026-07-22
**Pages audited:** 15
**Total issues found:** 25
**Scope:** `<title>`, meta description (120–160 chars), OpenGraph tags, canonical URL, JSON-LD schema, robots directive

## Summary

- **6 pages** have no `<link rel="canonical">` tag: `auth.html`, `privacy.html`, `terms.html`, `success.html`, `cancel.html`, `reset-password.html`
- **3 pages** (`success.html`, `cancel.html`, `reset-password.html`) are missing `og:title`, `og:description`, and `og:url` — only `og:image` is present, so links shared from these pages will show a generic/broken preview
- **7 pages** have a meta description outside the 120–160 char target: `marketplace.html` (161, over) and `auth.html`, `contact.html`, `privacy.html`, `terms.html`, `success.html`, `cancel.html`, `reset-password.html` (all under 120)
- `index.html` is the only page with JSON-LD schema required by the checklist; it has it. 7 of the other 14 pages also carry schema (`marketplace`, `find-trucks`, `pricing`, `about`, `jobs`, `venues`, `property`) — not required, noted as a bonus, not a fail
- `auth.html`, `success.html`, `cancel.html`, `reset-password.html` are marked `noindex, nofollow`. This looks intentional (auth/utility/post-checkout pages) rather than a mistake, but is flagged per check #9 for confirmation
- **Data accuracy (bonus finding, outside the 9-point checklist):** `jobs.html` og:description and JSON-LD both say "across 21 SWFL cities" — the project reference (`CLAUDE.md`) states the city count is always **22**. This is a copy/data bug, not a metadata-completeness gap.

### Top 3 priority fixes

1. **Add `og:title` / `og:description` / `og:url` to `success.html`, `cancel.html`, `reset-password.html`** — these currently only have `og:image`, so any link shared from a post-checkout or password-reset flow renders a broken/generic social preview.
2. **Add canonical tags to the 6 pages missing them** (`auth.html`, `privacy.html`, `terms.html`, `success.html`, `cancel.html`, `reset-password.html`) — leaves those URLs without a self-referencing canonical, which is a routine but easy duplicate-content gap to close.
3. **Rewrite the 7 out-of-range meta descriptions** — `marketplace.html` is 1 char over the 160 max; `auth.html`, `contact.html`, `privacy.html`, `terms.html`, `success.html`, `cancel.html`, `reset-password.html` are all under the 120 min (as short as 34 chars on `reset-password.html`), so search snippets are getting auto-generated instead of using the authored copy.
